# Git Branching & Merging Tutorial

This repository contains a single interactive learning page for Git branching and merging concepts.

## Contents

- `git_learn.html` — a self-contained HTML tutorial covering:
  - why branches exist
  - branch workflow concepts
  - merge scenarios
  - interactive command examples and quizzes

## How to Use

1. Open `git_learn.html` in your browser.
2. Read through the sections to learn Git branching and merging.
3. Use the on-page examples and quiz interactions to test your understanding.

## Website:-
https://shreyaaaaaak.github.io/git_learn/

## Notes

- This project is static and does not require any server or build tools.
- The page is styled with embedded CSS and includes interactive elements powered by JavaScript.

## Recommended Workflow

- Use this page as a study aid alongside a Git repository.
- Practice the commands in a real repository terminal for hands-on learning.
